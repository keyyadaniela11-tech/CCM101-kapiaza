## Brief Overview

Google Cloud Platform (GCP) is Google's suite of cloud computing services, built on the same global infrastructure that powers Google Search, YouTube, and Gmail. It reached general availability in 2011.


## Global Infrastructure

GCP operates a smaller but rapidly growing number of regions compared to AWS and Azure, connected through Google's own private global fiber network, which is frequently cited for low-latency performance between regions.


## Cloud Management Console

The Google Cloud Console is the primary web-based dashboard, supported by the gcloud CLI and the built-in Cloud Shell for browser-based command-line access.


## Four (4) Core Services

    • Compute Engine — customizable virtual machines
    • Cloud Storage — scalable object storage
    • BigQuery — serverless data warehouse and analytics
    • Google Kubernetes Engine (GKE) — managed Kubernetes container orchestration


## Three (3) Advantages

    • Industry-leading strength in data analytics, AI, and machine learning tooling
    • Competitive, granular (per-second) billing and sustained-use discounts
    • Best-in-class Kubernetes support, since Google originally created Kubernetes


## Typical Enterprise Use Cases

Data-driven companies running large-scale analytics; AI/ML research and model training; and startups or enterprises building containerized, cloud-native applications.
