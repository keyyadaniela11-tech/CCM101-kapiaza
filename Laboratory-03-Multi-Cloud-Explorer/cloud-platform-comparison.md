## Comparison Questions

### 1. Which cloud provider offers the broadest range of services?
AWS generally offers the broadest range of services because it has the longest track record of any provider and the largest overall service catalog, covering everything from basic compute and storage to specialized tools.

### 2. Which provider best integrates with Microsoft technologies?
Azure integrates most closely with Microsoft technologies since it was built specifically to extend Windows Server, Active Directory, and Microsoft 365, which makes it the easiest option for organizations already running on Microsoft software.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform tends to lead in AI/ML and Kubernetes, since Google created both TensorFlow and Kubernetes, and its infrastructure was designed around large-scale data processing and machine learning workloads.

### 4. Which cloud platform would you personally choose and why?
I would lean toward Google Cloud Platform for a project involving data analysis or machine learning, since its tools like BigQuery and Vertex AI make it easier to process and analyze large datasets, and its Kubernetes support would help if I ever needed to deploy containerized applications.
