## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform, launched in 2010. It provides infrastructure, platform, and software services that are closely integrated with Microsoft's existing enterprise software ecosystem.


## Global Infrastructure

Azure operates in more geographic regions than any other major cloud provider, with regions commonly organized into paired regions for disaster recovery, and an expanding Availability Zone model in select regions.


## Cloud Management Console

The Azure Portal is the primary web-based management interface. Azure also supports management through Azure CLI, PowerShell, and Azure Resource Manager (ARM) templates.


## Four (4) Core Services

    • Azure Virtual Machines — on-demand scalable computing
    • Azure Blob Storage — object storage for unstructured data
    • Azure Active Directory / Microsoft Entra ID — identity and access management
    • Azure SQL Database — managed relational database service


## Three (3) Advantages

    • Seamless integration with Windows Server, Active Directory, and Microsoft 365
    • Strong hybrid-cloud tools (e.g., Azure Arc) for organizations that keep some infrastructure on-premises
    • Enterprise-friendly licensing, support agreements, and compliance certifications

## Typical Enterprise Use Cases
Organizations already invested in Microsoft products migrating to the cloud; hybrid-cloud deployments that mix on-premises and cloud resources; and enterprises needing strong identity and compliance management tied to existing Active Directory.
