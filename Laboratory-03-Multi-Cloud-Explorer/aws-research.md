## Brief Overview

Amazon Web Services (AWS) is Amazon's cloud computing platform, launched in 2006. It was the first major public cloud provider and remains the largest in terms of market share and breadth of services, offering on-demand compute, storage, databases, and hundreds of other tools on a pay-as-you-go basis.

## Global Infrastructure

AWS organizes its infrastructure into geographic Regions, each made up of multiple isolated Availability Zones for fault tolerance and high availability. AWS operates in over 30 Regions worldwide, backed by a large network of Edge Locations used for content delivery through Amazon CloudFront.

## Cloud Management Console

The AWS Management Console is the web-based dashboard used to configure and monitor AWS services. AWS also provides the AWS CLI and SDKs for programmatic access.

## Four (4) Core Services

    • Amazon EC2 (Elastic Compute Cloud) — resizable virtual server instances
    • Amazon S3 (Simple Storage Service) — scalable object storage
    • Amazon RDS (Relational Database Service) — managed relational databases
    • AWS Lambda — serverless, event-driven compute

## Three (3) Advantages

    • Broadest and most mature catalog of cloud services of any provider
    • Extensive global infrastructure with high availability and redundancy
    • Large ecosystem of third-party tools, partners, and community support

## Typical Enterprise Use Cases

Startups needing to scale quickly without large upfront infrastructure costs; large-scale e-commerce and media streaming platforms; big data analytics; and enterprises migrating legacy on-premises workloads to the cloud.
