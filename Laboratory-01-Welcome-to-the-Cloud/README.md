# Laboratory 01 - Welcome to the Cloud

## Mission Overview
This lab was my first onboarding mission as a Junior Cloud Infrastructure Engineer Trainee. It focused on getting hands-on with a Linux environment, exploring system information, and setting up a GitHub portfolio to document ongoing cloud computing lab activities.

## Objectives
- Launch and explore a Linux environment using KillerCoda
- Create a new user account with sudo access
- Investigate and record key Linux system information
- Build an organized local workspace and a GitHub portfolio repository

## Activities Performed
- Launched an Ubuntu 24.04 playground on KillerCoda
- Created a new user (kapiaza) with a home directory, Bash shell, and sudo access, then logged in to it
- Gathered and documented Linux distribution, kernel version, CPU information, total memory, and available disk space
- Built a local folder structure (Notes, Reports, Screenshots) and wrote a personal about-me.md
- Created this GitHub repository to host the lab documentation

## Linux Commands Used
- adduser, usermod, su
- lsb_release, uname, lscpu, free, df
- mkdir, cd, nano, cat, ls

## Skills Learned
- Basic Linux user administration and permissions
- Reading and interpreting system information commands
- Writing documentation in Markdown
- Git/GitHub workflow for building a project portfolio
